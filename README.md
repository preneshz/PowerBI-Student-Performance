# PowerBI-Student-Performance
Interactive Power BI dashboard analyzing Anna University student database, covering academic performance, attendance, internships, satisfaction, and teaching quality. Provides department-wise and year-wise insights through interactive visualizations and filters.

# 🎓 College Education Quality and Student Performance Analysis

## 📊 Project Overview

This project is an interactive **Power BI dashboard** created using an **Anna University student database**. The purpose of this project is to analyze student academic performance and understand different factors that contribute to education quality.

The dashboard presents the data in a simple and interactive way, allowing users to explore student information based on **department and academic year**.

## 🎯 Objectives

- Analyze overall student academic performance.
- Compare average marks across different departments.
- Study student attendance levels.
- Analyze student satisfaction and mentoring support.
- Understand internship participation and status.
- Evaluate teaching quality.
- Provide department-wise and year-wise insights.

## 📈 Dashboard Features

The Power BI dashboard includes:

- **Total Student Count**
- **Average Attendance**
- **Average Student Marks**
- **Average Student Satisfaction**
- **Department-wise Performance**
- **Mentoring Support Analysis**
- **Internship Status**
- **Teaching Quality**
- **Department and Year Filters**

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard creation and visualization
- **DAX** – Data calculations and measures
- **Data Analysis** – Student performance analysis
- **Data Visualization** – Charts, KPIs, and interactive filters
